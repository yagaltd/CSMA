# Wave 1 Contract — Shared API Signatures

Agents implementing phases 10, 13, 15, 18, 19 must agree on these signatures.
All methods belong to `MindmapService` unless noted otherwise.

## Phase 15 — New service methods (MindmapService.js)

```js
// Insert a new node as sibling before or after nodeId.
// Creates a branch or leaf depending on position context.
// Returns the new node.
async insertSibling(nodeId, position, topic, meta = {}, options = {})
// position: 'before' | 'after'
// Fires MINDMAP_NODE_ADDED with parentId from the sibling's parent.

// Wrap nodeId in a new parent branch. The new parent takes nodeId's
// position in the grandparent's children array; nodeId becomes a child.
// Returns { parent: NodeObj, child: NodeObj }.
async insertParent(nodeId, options = {})
// Fires MINDMAP_STRUCTURE_CHANGED.

// Reorder nodeId one position up/down within its parent's children array.
// Returns the node (same object, new position).
async moveUp(nodeId, options = {})
async moveDown(nodeId, options = {})
// Fires MINDMAP_NODE_MOVED.
```

## Phase 19 — Layout direction (MindmapService.js)

```js
// Set global layout direction for the active map.
// direction: 0=left, 1=right, 2=side (both), 3=down (top-down).
// Iterates root children and sets their .direction field,
// then fires MINDMAP_STRUCTURE_CHANGED.
async setLayoutDirection(direction, options = {})

// Returns the current global layout direction (number 0-3).
getLayoutDirection(mapId?)
```

## Phase 10 — Selection events (new contracts in mindmap-contracts.js)

```js
MINDMAP_NODE_SELECTED     // { mapId, nodeId }
MINDMAP_NODES_SELECTED    // { mapId, nodeIds: string[] }
MINDMAP_SELECTION_CLEARED // { mapId }
MINDMAP_NODE_EDIT_START   // { mapId, nodeId }
MINDMAP_NODE_EDIT_END     // { mapId, nodeId, committed: boolean }
```

## Phase 13 — ViewportController (new file: services/ViewportController.js)

```js
class ViewportController {
  // el: the canvas container element
  // nodeLayer: the transformable div containing nodes
  // connectorLayer: the SVG layer (same transform)
  constructor({ container, nodeLayer, connectorLayer, eventBus, mapId })

  // Transform state
  get tx()       // number, current translateX (px)
  get ty()       // number, current translateY (px)
  get scale()    // number, current scale (0.2–1.4)

  // Apply transform to nodeLayer + connectorLayer
  _applyTransform()

  // Pan by delta (px). Smooth=false for wheel, smooth=true for animations.
  move(dx, dy, smooth = false)

  // Scale to newVal centered on {cx, cy} (client coordinates).
  // Clamps to [scaleMin, scaleMax]. If cx/cy omitted, scales from center.
  scaleTo(newVal, { cx, cy } = {})

  // Reset transform so root node is centered in viewport.
  // Needs access to layout result (root x/y/w/h) — caller passes rootRect.
  toCenter(rootRect)

  // Auto-scale so all nodes fit in viewport.
  // nodesRect: { x, y, w, h } bounding box of all node positions.
  scaleFit(nodesRect)

  // Scroll to make nodeId visible (pan so node center is in viewport).
  // nodeRect: { x, y, w, h } in layout coordinates.
  scrollIntoView(nodeRect, forceCenter = false)

  // Destroy: remove event listeners.
  destroy()

  // Config
  scaleMin = 0.2
  scaleMax = 1.4
  scaleSensitivity = 0.1
}

// Event published (debounced, ~16ms throttle):
MINDMAP_VIEWPORT_CHANGED  // { mapId, tx, ty, scale }
```

## Integration rules

1. **No agent edits demo/mindmap.html** — each agent produces a standalone file.
   The parent agent integrates everything into demo/mindmap.html after all
   Wave 1 agents complete.
2. **Phase 15 and Phase 19 both edit MindmapService.js** — Phase 15 agent adds
   methods first (insertSibling, insertParent, moveUp, moveDown), then signals
   completion. Phase 19 agent reads the updated file and appends
   setLayoutDirection/getLayoutDirection. Or: a single combined agent does both.
3. **Phase 10 agent produces `services/SelectionController.js`** — a standalone
   class that manages node selection state and inline editing. Imported by demo.
4. **Phase 18 agent edits** `src/style/token-overrides.json` — adds mindmap
   token section. Creates `src/modules/mindmap/i18n/mindmap-en.json`.
