aiui Catalog: the generation loop

This page proves the compose half of the CSMA component workflow: every gallery card below is mounted through AIUIComposerService from the generated componentCatalog, the same path slides and archetypes use.

  1. npm run create-component <name>: scaffolds manifest + CSS + preview in src/ui/components/<name>/
  2. Edit the generated manifest / props to fit the brief
  3. npm run generate-ai-ui-catalog: regenerates the catalog (generated artifact, never hand-edited)
  4. Compose via the composer / aiui ops, as this page does
  5. npm run check:design + npm run check:styles gates

Core seed components (owner: core)

Mounted live via composer.compose({ component: id, props }).

Module surfaces (owner: module)

Registered but not mounted here: they need their owning module's service via ServiceManager. See the slides demo for the full mountSurface path.
