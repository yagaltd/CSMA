Architecture Overview

CSMA separates concerns: JavaScript manages state via events, CSS handles rendering. This achieves fast DOM updates and a minimal bundle size.

CSMA is modules-first. Prefer trusted modules under src/modules/*, Contracts for validation and security, and lifecycle-safe load/unload through ModuleManager.

The 6 Rules

  1. State Changes = CSS Classes Only — no inline styles for UI state
  2. Define All States in CSS — use data-* attributes
  3. JavaScript Publishes Events, CSS Handles Rendering
